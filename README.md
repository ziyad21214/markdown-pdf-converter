# Description
A simple web-based file converter with a flask back-end that delivers seamless, low-latency file format conversion through a clean, modular RESTful API.
Currently only supporting .md and .pdf file formats but more will be added soon..

# Getting started
```bash
git clone https://github.com/ziyad21214/markdown-pdf-converter
cd markdown-pdf-converter
pip install -r requirements.txt
flask run
```
